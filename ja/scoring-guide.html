採点の実践ガイド

点数が同じでも、結論はひとつとは限らない

比較表を作るときに大切なのは、点数の高さよりも「何を重視して、どう採点したか」を説明できることです。架空の旅行プラン3案を使い、同点の読み方、重み付けによる順位の変化、未採点の扱いを一つずつ検証します。実在の旅行プランの価格や評価ではありません。

1. 採点を始める前のルール

最初に「選びたいこと」を一文で決め、すべての候補に同じ評価項目を適用します。例えば旅行なら「楽しさ」「手頃さ」「移動のしやすさ」の3つ。今回は10点満点で、どの項目も数値が大きいほど望ましい状態を表すように統一します。「手頃さ」は値段そのものではなく、予算に収まりやすいほど高得点とします。

項目2点の例5点の例9点の例
楽しさ希望する活動がほとんどない楽しみはいくつかあるぜひ体験したい活動が多い
手頃さ予算を大きく超える予算とほぼ同じ予算に十分余裕がある
移動のしやすさ乗り換えや移動負担が多い許容できる移動量移動が短く簡単

数値は以下の計算を試すための創作例です。実際の料金や移動時間を評価するなら、比較した日付・出典・交通条件も記録してください。

2. 元データを隠さずに平均を計算する

架空のA・B・Cの旅行プランを採点してみます。項目ごとの点数が違うので、総合点だけでなく元データも見せるのが重要です。

候補楽しさ手頃さ移動単純平均楽しさを重視 2:1:1
プランA9587.337.75
プランB7877.337.25
プランC6967.006.75

小数第3位を四捨五入して小数第2位まで表示しています。プランAとBは単純平均で同点ですが、Aは楽しさ、Bは手頃さに強みがあります。ランキングだけを見るとこの差を見落としやすいため、複数の得意分野を比較するならレーダーチャートも役立ちます。

3. 重みを変えると順位が逆転する

単純平均ではすべての項目が1:1:1です。楽しさを2倍に重視する場合は「楽しさ×2、手頃さ×1、移動×1」を重みの合計4で割ります。プランAは(9×2 + 5 + 8)÷4 = 7.75、Bは(7×2 + 8 + 7)÷4 = 7.25です。

反対に予算重視で「楽しさ1、手頃さ3、移動1」にすると、プランAは(9 + 5×3 + 8)÷5 = 6.40、Bは(7 + 8×3 + 7)÷5 = 7.60、Cは(6 + 9×3 + 6)÷5 = 7.80となり、Cが首位になります。これは計算の間違いではなく、「何を大切にするか」が変わった結果です。

重みを変更する前に、用途や判断の目的を説明しましょう。希望する順位に合わせてあとから重みを操作すると、読者が結果を再現できません。

4. 未採点・同点・偏りをどう扱う？

未採点は0点と同じではありません。0点を明示的に付けた場合と、まだ評価していない場合は区別してください。データがそろわなければ、空欄のままにして説明文で補足するか、全候補を同条件で測り直す方が安全です。集計結果の扱いは、実際に使う採点モードとグラフ設定で確認しましょう。

同点でも項目ごとの内訳が違えば、特徴は別です。細かな順位が必要なら同点のまま表示するか、事前に同点時の判定基準を決めましょう。数値を恣意的に変更して同点を解消しないでください。

複数の人で評価する場合は、尺度の解釈と採点条件をそろえます。個人の感想と、料金・移動時間などの客観的データは混同しないように記載しましょう。

5. Stats Makerで同じ比較を再現する

  1. ホームの採点表で3行（プランA・B・C）と3項目（楽しさ・手頃さ・移動）を作ります。
  2. 採点尺度を10点満点にし、表の数値を順番に入力します。既存の点数を維持したまま尺度を切り替える場合は、換算仕様を確認してください。
  3. 単純平均の比較を確認してから、重み設定を使う場合は2:1:1や1:3:1を入力します。変更後は全候補の点数と順序を見直します。
  4. 得意分野を見るならRadar Chart、合計順を見るならRanking Card、段階分けならTier Listを選びます。完成したPNGと、後で編集するための保存データは別物です。
  5. 画像を共有する前に「架空の例」「採点尺度」「重み」「主観か客観か」を明記してください。公開せずに画像だけ保存することもできます。
