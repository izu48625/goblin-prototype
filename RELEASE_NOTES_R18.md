# Stats Maker R18 Integrated Candidate

R14 local-complete base + R15 Publish + R16 Public Viewer + R17 Remix + R18 Community.

## R15 Publish
- Login remains optional until Publish.
- Public / Unlisted / Private.
- Published creator snapshot.
- Community-safe publish updates. If structure changes after Community submissions, R18 automatically creates a new topic version and preserves the old Community data.

## R16 Public Viewer
- Read-only creator score table and creator ranking.
- Mobile responsive public URL.

## R17 Remix
- One-click public topic -> local Stats Maker sheet.
- Creator scores are copied as the Remix starting point.
- Source topic ID is retained locally.

## R18 Community
- Anonymous participation through Supabase Anonymous Auth.
- Draft save + submit/update rating.
- One participant / one rating set per topic.
- Community participant count.
- Community item ranking.
- Per-criterion averages.
- You vs Community comparison.
- Privacy threshold inherited from DB-R2: averages remain NULL until 5 eligible responses.
